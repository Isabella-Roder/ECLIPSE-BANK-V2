# Eclipse Bank V2

Nova versão do Eclipse Bank, reconstruída do zero com Java e Spring Boot. O objetivo é aplicar arquitetura em camadas, segurança, testes e regras bancárias consistentes.

> Projeto em desenvolvimento. A versão original está disponível em [ECLIPSE-BANK](https://github.com/Isabella-Roder/ECLIPSE-BANK).

## Tecnologias iniciais

- Java 26
- Spring Boot
- Maven
- Spring Data JPA
- Bean Validation
- H2 persistente no desenvolvimento

Consulte o planejamento em [Requisitos.md](Requisitos.md).
